# 무무 크레용 · 백 장의 종이 정원

그린 네모에 무게가 생기고, 빨간 원이 굴러가 햇살 별을 만나는 물리 그림 놀이입니다. 퍼즐을 푼 장면에 색연필로 나만의 그림을 더할 수 있습니다.

**[바로 플레이하기](https://reinhardt7177-lab.github.io/mumu-crayon/)** · [100개 스테이지](docs/CAMPAIGN-100.md) · [배포와 업데이트](docs/DEPLOYMENT.md)

설치나 로그인 없이 브라우저에서 플레이합니다. PC에서는 마우스, 터치 화면에서는 드래그로 그리세요. 작은 화면은 가로 방향을 권장합니다.

## 놀이 방법

| 도구 | 사용법 |
|---|---|
| 네모 | 대각선으로 드래그합니다. 큰 네모는 더 무겁습니다. |
| 물리펜 | 선을 그려 다리나 막대를 만듭니다. |
| 색연필 | 물리 충돌이 없는 그림을 그립니다. |
| 지우개 | 내가 그린 물체와 보라색 장애물을 지웁니다. 오른쪽 클릭으로도 지울 수 있습니다. |
| 예시 재생 | 가능한 해법 하나를 실제 물리로 관찰합니다. 완료 기록에는 반영하지 않습니다. |
| 작품 담기 | 완성한 장면을 내 스케치북에 저장합니다. PNG로 내려받을 수 있습니다. |

`P` 일시정지 · `Space` 다시 시작 · `Ctrl+Z` 되돌리기 · `1/2/3/4` 도구 선택

진행과 작품은 **사용 중인 브라우저에 저장**됩니다. 다른 기기와 자동으로 동기화하지 않습니다. 소중한 그림은 PNG로 내려받으세요.

## 100개 페이지

10개 챕터에서 무게와 낙하, 다리, 비탈, 연쇄 반응, 시소, 매달린 문, 지우기, 위아래 길과 방향 전환을 만납니다. 모든 스테이지는 목차에서 자유롭게 선택할 수 있습니다. 색·명암·리듬·구도를 다루는 미술 미션에는 정답이나 점수가 없습니다.

후반 51~100번은 앞에서 배운 원리를 연결하도록 재구성했습니다. 마지막 페이지는 위쪽 세 별과 아래쪽 두 별을 모두 모읍니다. 그리기 횟수나 다리 길이에 제한을 두지 않아 다른 해법도 시도할 수 있습니다.

## 로컬 개발과 검증

Node.js 24 이상과 Python 3을 사용합니다. npm 의존성 설치는 필요하지 않습니다.

```sh
npm test
npm run build
npm run check:site
python -m http.server 8137 --bind 127.0.0.1 --directory dist
```

브라우저에서 <http://127.0.0.1:8137/>를 여세요. `dist`에는 게임 실행에 필요한 파일만 들어갑니다. `main`에 올리면 같은 검사를 통과한 뒤 GitHub Pages로 자동 배포됩니다.

자동 검사에서는 100개 배치의 물리 안정성과 저장된 해법의 모든 별 획득을 확인합니다. 브라우저용 예시 입력은 실제 브라우저에서 별도로 검증했습니다. 직접 그리며 확인한 후반 표본은 71·80·100번입니다. 전체 자동 검사와 모든 스테이지를 사람이 직접 플레이하는 것은 구분합니다.

## 구성

- `src/core.js`: Matter.js 기반 물리·충돌·별 획득
- `src/app.js`: 그리기, 지우기, 효과음, 진행·작품 저장
- `src/mumu-art.js`: 종이 정원과 크레용 렌더링
- `src/campaign-levels.js`: 10개 챕터·100개 퍼즐
- `src/campaign-examples.js`: 브라우저에서 검증한 예시 입력
- `src/campaign-ui.js`: 목차·검색·챕터·페이지 이동
- `tools/`: 물리 검증과 정적 배포 도구

## 제작과 사용 구성 요소

Crayon Physics의 그리기·무게·충돌 원리를 연구한 새 게임입니다. 퍼즐 배치, 그림, 화면과 효과음은 무무 크레용을 위해 새로 구성했습니다. 원본 게임의 그림·음악·실행 파일을 배포하지 않습니다. 물리 엔진과 접촉·마찰·관절의 동작은 원작과 차이가 있습니다.

Matter.js 0.20.0(MIT), Gaegu 및 Finger Paint(SIL OFL 1.1)를 사용합니다. 저작권과 라이선스 전문은 [사용 구성 요소 안내](THIRD_PARTY_NOTICES.md)에 있습니다. 프로젝트 전체의 별도 오픈소스 라이선스는 지정하지 않았습니다.
