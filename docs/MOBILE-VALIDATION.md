# 모바일 화면과 입력 검증

2026-10-22 공개판에서 작은 조작 버튼과 가로 화면의 겹침·가로 넘침을 수정했습니다. 종이의 4:3 비율과 800×600 물리 좌표, 100개 퍼즐의 배치는 유지합니다.

## 화면

- 세로: 320×568, 360×640, 390×844, 430×932.
- 가로: 667×375, 844×390.
- CUA로 데스크톱 Chromium의 실제 브라우저 표시 영역을 변경하고 렌더링·조작 영역을 확인합니다. 기기 이름이나 사용자 에이전트를 바꾼 검사는 아닙니다.
- 휴대폰은 가로 플레이를 기본으로 합니다. 폭 760px 이하 세로 화면에서는 회전 안내를 표시하고 물리와 그리기를 막습니다. 가로로 돌아오면 그린 물체·선택 스테이지·직접 설정한 일시정지 상태를 유지해 이어집니다. 브라우저가 기기의 방향을 강제로 바꾸는 기능은 사용하지 않습니다.
- 주요 게임 버튼은 최소 44×44 CSS px입니다. 휴대폰 가로 화면은 도구를 종이 오른쪽에 놓습니다.
- 색상 줄은 좁은 도구함 안에서만 옆으로 스크롤됩니다. 문서 전체에는 가로 스크롤이 생기지 않습니다.
- 회전으로 표시 크기가 바뀌면 진행 중이던 선만 취소합니다. 이미 그린 물체와 퍼즐 기록은 남습니다.

## 터치 입력과 물리

`node tools/verify_input.cjs`는 배포 코드 `src/canvas-input.js`에 `pointerType: touch` 입력을 보내 실제 Matter.js 물리 세계까지 연결합니다. 다섯 가지 캔버스 폭에서 다음을 검사합니다.

1. 손가락 드래그 좌표를 종이 좌표로 바꾸어 네모·막대를 만듭니다.
2. 지우개 누르기와 문지르기로 그린 충돌 물체를 제거합니다.
3. 만들어진 네모가 떨어져 빨간 원과 충돌하고, 원이 굴러 별을 얻어 완료됩니다.
4. 두 번째 손가락이 첫 선을 덮거나 취소하지 않습니다.
5. 취소·포인터 캡처 상실·화면 전환 뒤에 유령 물체나 끝나지 않은 선이 남지 않습니다.
6. 종이를 벗어난 드래그는 경계 안으로 제한합니다. 시작·끝만 전달된 빠른 물리펜 동작도 직선 막대로 만듭니다.

입력 검사에서는 이벤트 대상을 모의로 구성합니다. 실제 휴대폰이나 브라우저의 네이티브 터치를 발생시키는 검사는 아닙니다. 실제 브라우저에서의 드래그·지우기·별 획득은 휴대폰 크기 화면에서 별도로 확인합니다. 현재 도구가 보내는 브라우저 드래그는 마우스 입력이므로 손가락 입력과 구분합니다.

## 확인 범위

실제 iPhone Safari·Android Chrome 기기는 연결하지 않았습니다. 기기별 성능, 브라우저 주소창의 펼침·접힘과 운영체제의 실제 터치 동작을 실기 검증했다고 주장하지 않습니다. 자동 입력 검사와 화면 검사는 `npm test`, `npm run build`, `npm run check:site`에 포함하거나 별도 브라우저 기록으로 남깁니다. 기존 100스테이지 해법 검사도 계속 실행합니다.
